# Ícones de tecnologias

Ícones obtidos do projeto [Devicon](https://github.com/devicons/devicon), em `icons/<tecnologia>/<tecnologia>-original.svg`.

As cópias locais mantêm as cores e os desenhos originais. A licença está preservada em `LICENSE.devicon`.

Os nomes e símbolos das tecnologias pertencem aos seus respectivos titulares.
